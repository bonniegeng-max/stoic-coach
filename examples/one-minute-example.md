# One-Minute Example

## User request

```text
明天要做一个重要汇报，我一直担心领导不认可。带我做一分钟控制二分法。
```

## Example response

**发生了什么**

你明天要做一次重要汇报，现在担心最终评价不理想。

**此刻属于你选择的**

- 把核心结论压缩成一句话。
- 检查最可能被追问的两个数据。
- 决定开场时放慢语速并先讲结论。

**你能影响、但不能决定的**

- 对方是否认可方案。
- 现场问题的难度。
- 会议时间是否临时缩短。

**不属于你控制的**

- 对方当时的情绪和偏好。
- 汇报结束后的最终决策。

**下一步**

现在用 10 分钟写下“一句话结论 + 两个证据 + 一个备选方案”，然后停止继续模拟所有可能的失败。

This example shows the intended brevity. It does not diagnose anxiety or promise that the exercise will change the outcome.
